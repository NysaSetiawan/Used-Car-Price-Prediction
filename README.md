# Used-Car-Price-Prediction
Neural Network-based used car price prediction on 2,000 vehicle records, achieving 89.9% R² with MAE of 1,649.

A Neural Network regression project for predicting used car selling prices based on vehicle characteristics.

### Key Results
- Analyzed **2,000 vehicle records** with **18 features**.
- Built a Neural Network regression model using TensorFlow/Keras.
- Evaluated performance using **MAE, RMSE, and R²**.
- Achieved **R² of 0.899**, explaining approximately **89.9% of the variance** in selling prices.
- Achieved **MAE of 1,649.83** and **RMSE of 2,866.10** on the test set.
- Compared a baseline architecture with a regularized model using **L2 Regularization, Batch Normalization, and Dropout**.
- The baseline model achieved slightly better test performance than the modified model.

### Technologies
Python, TensorFlow, Keras, Pandas, NumPy, Scikit-learn
